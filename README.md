# Настолки — каталог настольных игр

Учебный проект по дисциплине «Введение в интернет-технологии».
Сайт-каталог настольных игр с подбором по числу игроков и длительности партии.

**Вариант:** №10, группа А («Каталог и подбор»).

## Что уже сделано (ПР 1)

Статическая часть сайта из семи связанных страниц:

- `index.html` — главная: назначение сайта, меню, подборка из 6 популярных игр.
- `catalog.html` — каталог из 15 игр, разметка фильтров и сортировки.
- `game.html` — подробная страница игры «Каркассон»: описание, характеристики, цена.
- `compare.html` — сравнение трёх игр по характеристикам в одной таблице.
- `about.html` — страница «О проекте»: назначение сайта, что можно сделать, технологии.
- `contacts.html` — адрес, телефон, режим работы, слоган и форма обратной связи.
- `404.html` — оформленная страница ошибки с кнопкой возврата на главную.

Оформление:

- единый файл стилей `style.css`, подключён ко всем страницам;
- макет на Flexbox и Grid, без абсолютного позиционирования;
- адаптивность: страницы корректно отображаются при ширине 360 px;
- семантическая разметка (`header`, `nav`, `main`, `article`, `footer`, `table`);
- один `<h1>` на страницу, заполнены атрибуты `alt` у изображений;
- кодировка UTF-8, указаны язык страницы и мета-тег viewport;
- собственный логотип `images/logo.svg` и favicon `images/favicon.svg`;
- изображения игр хранятся локально в `images/games/`, уменьшены до разумного размера;
- в карточках каталога картинка и название ведут на страницу игры.

> Фильтры, кнопки сравнения и форма обратной связи пока только размечены — они заработают в следующих практических работах.

## Как запустить

### Вариант 1 (через Live Server)

1. Открыть папку проекта в VS Code.
2. Установить расширение **Live Server**.
3. Нажать правой кнопкой по `index.html` → **Open with Live Server**.
4. Сайт откроется в браузере и будет обновляться при сохранении файлов.

### Вариант 2 (без расширений)

Открыть файл `index.html` двойным щелчком — сайт откроется в браузере.
